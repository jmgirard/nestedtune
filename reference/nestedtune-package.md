# nestedtune: Nested Cross-Validation for Tidymodels

Builds and orchestrates nested cross-validation designs for the
tidymodels ecosystem. Provides a memory-lean nested resampling
constructor whose object size does not grow with the outer fold count,
producing the same splits as 'rsample'.
