- Variance estimation / inference on the nested estimate — added 2026-07-25 — G6. - An analytic oracle for the outer loop via `parsnip::null_model()` — added 2026-07-31 — from `references/nachum2026.md`. Theorem 4.10 plus Lemma 4.9 give an exact closed form for the k-fold CV MSE of the majority algorithm under Bernoulli(1/2) labels: MSE = ((k-1)/k)*Cov(n,m) + 1/(4n) with Cov(n,m) = 2^-n * sum_j C(m-1,j)^2 * C(n-2m, floor((n-m)/2) - j). `parsnip::null_model(mode = "classification")` instantiates that algorithm and carries no tuning parameters (verified present 2026-07-31). Would be the shelf's first GP2 type (3) oracle for the outer loop. Two unmeasured risks before it is plannable: `null_model()`'s tie-breaking at Y = n/2 is unchecked against the theorem's `Y > n/2` rule, and MSE is a distributional property, so the replicate count must be priced against GP4 the way `references/varma2006.md`'s null-data invariant already was
