# Lessons

_Durable "how this repo behaves" notes — build quirks, testing tricks,
toolchain gotchas. Captured at milestone end, harvested at plan time._

_One lesson per line. Current knowledge, not history: a lesson proven false
is **corrected in place** and marked (`(M07, corrected M11)`); git holds the
original. A lesson is **retired** — leaving no line behind — once a test
fails on the mistake it warns about, another tracking file's slot owns the
content, or a matured family graduates whole into a doctrine module._

_Hard cap: 50 lines._

## Lessons

- 2026-07-26 (M04, consolidated M12/M24, trimmed 2026-09-03): cli output. Reading it: cli writes to `stderr()` whenever a sink is active on stdout, so `capture.output()` around a cli print method captures nothing — use `cli::cli_fmt()` or `expect_snapshot()`. Writing it: `cli_alert_*()` never wraps, `cli_bullets()` wraps with a hanging indent, so sentences go in the latter. Pluralisation: cli takes a plural's quantity from the LAST interpolation, so put `{cli::qty(n)}` before a verb that must agree with an earlier count; and `cli_vec()` has three separator styles (`vec-sep`, `vec-last` at n > 2, `vec-sep2` at exactly n = 2), so setting `vec-last` alone renders two items with no separator. Pin snapshots at the counts where wording changes, not the ones that came out right.
- 2026-07-26 (M05, extended M54): an oracle asserting only the selection and the predictions does not guard where a seed is set, because a different RNG state usually picks the same candidate anyway and the fit is seeded separately. Assert the resamples the tuning run actually saw — and prove any such guard by inversion, since the plausible-sounding one here passed the mutation. Since M54 the resamples a fold's tune call saw are the design's `inner_resamples[[i]]` re-pointed at the outer analysis frame, so a live-oracle reference built by calling tune on `inner_resamples[[i]]` itself matches only while the grid carries no unknown range; an oracle for a data-finalized parameter builds its reference on `analysis_framed_inner()`'s output or on an `rsample::nested_cv()` design.
- 2026-07-26 (M05, extended M45, trimmed 2026-09-04): inlining a data frame into a call — `rlang::call_modify(cl, data = df)`, `rlang::call2(fn, object, ...)` — makes every downstream condition deparse the frame into its message (172,423 characters on a 400-row fixture against 149 over symbols). Bind the value in a child environment and pass the symbol.
- 2026-07-26 (M06, extended M61/M62/M64): a vignette using a Suggests package needs `requireNamespace()` + `knitr::knit_exit()` to survive CRAN's noSuggests flavor; chunk-level `eval = FALSE` is not enough, because inline `r` expressions still evaluate on objects the skipped chunks never created, so prose reading a guarded object goes in a guarded `results = "asis"` chunk. Before writing a masking or skip-on-absence criterion, read the package's `Priority` and each Import's recursive closure (`tools::package_dependencies(recursive = TRUE)`): a recommended package sits in the system library, unmaskable from `.libPaths()`, and a package inside an Import's closure (dials under tune; tibble under dplyr; nnet under tune → recipes → ipred) fails `library(nestedtune)` when masked and is present on the no-Suggests leg, so the criterion or `skip_if_not_installed()` certifies nothing.
- 2026-07-26 (M07): mirai starts every daemon on its own L'Ecuyer-CMRG stream, so a caller who has selected that same kind gets serial/parallel identity even from an implementation with no RNG kind pin at all. A test meant to catch a missing pin must use a third kind (Wichmann-Hill works); L'Ecuyer-CMRG is the one non-default kind with zero detection power. And mirai's two failure shapes both defeat the obvious check — neither `miraiError` nor the bare `errorValue` from a dead daemon inherits `"condition"`, and `conditionMessage()` *raises* on the latter. Classify what a worker returns by positively validating the expected shape, never by asking whether it is an error.
- 2026-07-26 (M08, consolidated M14, trimmed 2026-09-03): two faceting traps. A ggplot2 `breaks` function is called once per panel with only that panel's limits, so a per-panel decision must be recoverable from the limits alone — deciding over the pooled column changes every other panel. `facet_wrap()` defaults to `drop = TRUE`, so an empty factor level loses its panel and a faceting variable with no values errors at draw time; `drop = FALSE` fixes both, `scale_x_discrete(drop = FALSE)` likewise for an axis.
- 2026-07-26 (M08): assertions on `ggplot_build()` cannot see the part a reader meets. Rendering the figure and looking at it found a subtitle clipped at 7 inches and fractional breaks labelling three unanimous integer choices 2.950/2.975/3.000 — both invisible to a green 51-assertion suite. Render every new plot before approving its snapshot.
- 2026-07-26 (M07, extended M14, trimmed 2026-09-03): a test that hand-rolls the code path it means to cover pins nothing — `local_mocked_bindings()` does reach a mirai daemon, since `dispatch_folds()` serializes its worker by name. `test_local()` (pkgload, one file per process) and `test_check()` (installed, one process) are different daemon paths — `prime_daemons()` works under the first and is a no-op under the second — so a harness on the wrong one stresses a configuration the failure never occurs in.
- 2026-07-26 (M09, extended M14/M19/M21/M22/M26/M38, trimmed 2026-09-05): assertions that cannot fail, the pattern to check by hand. `system.time()` flags a slow run but never bounds a hang; `setTimeLimit()` does not interrupt a blocked `mirai::collect_mirai()`. `tryCatch(expr, condition = identity)` catches warnings, so `expect_null()` on a variable assigned inside it is vacuous. `identical(.Random.seed, before)` cannot show a check fired before the RNG was drawn — `exists(".Random.seed")` in a never-drawn session does. A passing test is evidence only once you confirm it runs the claim's code path. `tune::collect_metrics()` returns no `.estimate` unless `summarize = FALSE`, so a loop over `$.estimate` iterates `NULL`. A top-level `on.exit()` in an `Rscript` never fires — use `reg.finalizer(environment(), ..., onexit = TRUE)`. Mutation checks under `pkgload::load_all()`: every internal function is bound in the namespace AND the attached `package:` env, and a global-env test helper resolves the latter, so patching the namespace alone leaves the tests' copy intact — edit the source and reload.
- 2026-07-27 (M10, extended M24, trimmed 2026-09-03): `mirai::everywhere()` reaches every daemon but takes no `.timeout`, and `[` on a `mirai_map` blocks until every element resolves — poll `unresolved()` to a deadline, `stop_mirai()`, then read each `$data`. It serializes the HOST's copy of the expression, so under `covr` the daemons receive `covr:::count()` calls and a daemon without covr raises, classifying a healthy pool as silent (failed only the coverage job). Build the sent expression with `str2lang()` from a string, which no rewriting tool reaches.
- 2026-07-27 (M12, extended M20/M23, trimmed 2026-09-03): `rlang::hash()` is not stable across two identical constructions of a tidymodels object (recipe `terms` quosures capture their frame; `metric_set()`'s environment is self-referential). The fixture cache hashes a canonical form — environments by contents, named environments by name, cycles cut — keyed on call, arguments and RNG state, and on nothing about daemon state, so a `memoised()` parallel fixture is served the serial value and dispatches nothing: build parallel fixtures inline and assert `last_dispatch()`. A cache hit's `metric_set()` is a different closure, so `expect_identical()` against a local set fails on correct code. The same rule governs the wire: R serializes ordinary environments by CONTENTS and namespaces/globalenv BY REFERENCE, so a formula written inside a function drags its whole frame (26,549,958 B against 1,761 B at top level).
- 2026-07-27 (M15, extended M16, trimmed 2026-09-03): stopping mirai work. A console interrupt unwinds a blocked `collect_mirai()` and runs `on.exit()`; `stop_mirai()` cancels only on a dispatcher-backed pool (`daemons(n, dispatcher = FALSE)` is indistinguishable through `status()$connections`) and is inert on a resolved map, which makes an unconditional cancelling `on.exit()` safe. Testing it needs a genuine SIGINT from a detached `sh` that waits on worker marker files before `kill -INT` — fired on a timer it lands in whatever test runs twenty seconds later. `daemons(0)` returns in ~0.2 s with a task outstanding (orphans it, does not block); `daemons(url =)` on an occupied port raises in ~0.03 s.
- 2026-07-27 (M14, corrected M16, extended M23, trimmed 2026-09-03): a test suite says nothing about itself unless you make it. Under `R CMD check` the output is an end-of-run dump, so an in-band clock through unbuffered `stderr()` is the only timing; that needs a `Reporter` subclass (R6 members are locked; `check_reporter()` returns a string, not the object `MultiReporter` wants; a class in `tests/testthat.R` is invisible to test files) with `start_test()`/`end_test()` hooks. A bare `Rscript` sets no `NOT_CRAN`, so every `skip_on_cran()` test skips — assert the assertion count. The default reporter stops after 10 failures, so a mutation check read off it under-reports; use `SummaryReporter$new(max_reports = Inf)`.
- 2026-07-27 (M17, trimmed 2026-09-05): pkgdown publishes repo-internal markdown: `pkgdown:::package_mds()` globs every root and `.github/` `.md` against a hardcoded exclusion list with no config knob, so `CLAUDE.md` became `CLAUDE.html` on the site. Deleting the built HTML is not enough (`sitemap.xml` and `search.json` derive from `docs/**/*.html`) and `.Rbuildignore` does not help (pkgdown builds from the source tree); remove the source before the build.
- 2026-07-27 (M16, extended M21/M31/M48, trimmed 2026-09-03): every wait being individually bounded does not bound the suite — `test-parallel-classify.R` ran 12 s under bounds permitting 1008 s, and a CI cap killed it looking like a hang. Sum declared bounds per file against the cap; the `helper-time-budget.R` ledger re-reads its call sites by `file:line`, so any insertion above a budgeted call costs a renumbering pass. Two cap scopes are not interchangeable: a job cap that kills a cold dependency build before the cache-save step deadlocks every later run on the cold build, so size the job cap for the slowest install and put the hang bound on the test step (PROFILE names the current caps). A suite grown into the step cap dies mid-`test_check` with no output — before hunting a hang, read the step's duration on the default branch's recent runs and time the branch's new tests locally.
- 2026-07-27 (M13, extended M23/M26/M27, trimmed 2026-09-03): measuring object size. `lobstr::obj_size()` charges shared content once, so it is not additive; `serialize()` does not preserve sharing, so six references to one frame write six copies — measure the serialized stream for anything crossing a process, and count copies with `grepRaw()` on a NUMERIC column's bytes (CHARSXPs are memoised). A stream is not byte-stable across processes (pid in temp paths), so cross-process comparisons need a band; `load_all()` with srcrefs inflates closures (291,491 B against 524 B installed). A contiguous subset frame reproduces a sentinel's bytes without being a copy, so net out each frame's own contribution. Figures: `references/mori-backend-assessment.md`.
- 2026-07-30 (M18): `set.seed(s)` pins only the uniform generator, so a fixture whose *property* was found by search — not merely its values — is not reproducible under a different ambient `RNGkind()`. The metric-separation fixture split 3 of 3 outer folds by default, 1 of 3 under `normal.kind = "Box-Muller"`, and 0 of 3 under `L'Ecuyer-CMRG` or `sample.kind = "Rounding"`, while its comment claimed reproducibility. Pin the full triple the way the reference loops do, and restore the caller's kinds so the pin does not leak into the next file.
- 2026-08-30 (M30, extended M31, trimmed 2026-09-03): a red macOS `R CMD check` leg can fail upstream of this package — `gower`'s RSPM arm64 binary needs a libomp the runner lacks, so the install dies in ~1m36s, twice identically. A local `devtools::check()` passing on the same platform is what separates an upstream break from ours; read `otool -L` on the `.so` before blaming the diff. The narrow remedy is pak's `gower?source` in `extra-packages`, scoped by a `matrix.config.os` ternary (`R-CMD-check.yaml` carries it with the reasoning).
- 2026-08-30 (M28, extended M35/#37/M47, trimmed 2026-09-05): a claim about another package is not checkable from recall, in four kinds. Its EXPORT SURFACE: sweep the whole `NAMESPACE` reading what each name does, never by name-matching or re-checking what you already cited; an exported `@keywords internal` symbol carries no stability promise, so the ask is "promise this", not "export this". Its ARGUMENT DEFAULTS: read `args()` before writing a sentence about one, and state in the call any default a convention depends on (`tune::control_last_fit()` `allow_par` was read both ways from recall). Its CONDITIONAL BEHAVIOUR: `tune::attach_pkgs()` attaches nothing when the strategy is sequential, so nothing carries over from a branch this package forces upstream not to take — read that branch of the body. Its REFUSAL BOUNDARY: one refused probe shows a fence exists, not where it stands (parsnip's `check_pred_type_dots()` is an allowlist, not a per-model check); read the set the check tests and probe just inside it.
- 2026-08-30 (M33, extended M37, trimmed 2026-09-03): a repository-wide reformat moves every `file:line` citation the records hold — 124 across `references/`, `ROADMAP.md`, `benchmarks/` and one source comment — and only the `helper-time-budget.R` ledger is test-enforced. Repair with a `difflib` line map over each touched file, applied only where the cited content moved, and never blind: this repo's pages cite tune's `R/checks.R` and `R/parallel.R` by the same relative paths its own files use. Verify by resolving each citation to the symbol it names. `DECISIONS.md`'s template block sits at the END of the file, so a D-entry appended at end-of-file renders nowhere (D-030, then D-035 again) — append above `<!-- Template:` and re-read the heading in place.
- 2026-09-01 (M41, extended M65): a name already in use inside the package is where a new one collides. `summarize_folds()` gained `.eval_time` for `collect_metrics()` and `summary()`, and `autoplot(type = "performance")`, which names its panels through the same function, aborted on a duplicated factor level; `R/nested-tune-grid.R` already held an internal `collect_inner_metrics()` that the exported generic of that name would have shadowed silently. Before a shape change or a new export, grep every caller and every holder of the name.
- 2026-09-01 (M42, extended M46, trimmed 2026-09-03): a guard's message is tested with the argument shape its real callers use — `fixture_key()`'s depth guard named the argument from `names(args)`, which every test named and every real positional caller (`memoised()`) left empty. Build one request the way the production caller does and assert on that. And `fixture_key()` hashes the RNG state, so for a net-zero-RNG function (D-011) `first <- memoised(f()); set.seed(s); second <- memoised(f())` compares a cached object with itself: a reproducibility identity is asserted between two direct calls, never through `memoised()`.
- 2026-09-01 (M43): testthat hands an `expect_snapshot()` `transform` each cli message on its own, not the block as recorded, so a transform that looks past its message for context (the next bullet, the next section) sees nothing there. `scrub_tibble_body()`'s first cut searched for the bullet after the tibble body and errored on the lone message; the transform must be right about a vector holding only the lines it is scrubbing.
- 2026-09-01 (M44): a table that adds its own columns beside user-named ones overwrites a same-named column silently — `out$n <- count` over `agreement()`'s key list turned a parameter with id `n` into the count, indistinguishable from an untuned run — so any result keyed on user-chosen ids refuses or namespaces the collision, and a test plants it.
- 2026-09-02 (M50, extended M53/M58, trimmed 2026-09-03): every push to a PR branch restarts its whole `pull_request` matrix (16–24 min/leg), tracking-only commits included, since `paths-ignore` bites on `push` alone. While a PR waits on CI, hold docs-only commits local and push nothing until the merge; on a review resume, read `gh pr checks` first and merge the head already green. `gh pr merge --delete-branch` then force-deletes the local branch, withheld commits included (reflog keeps them), so carry their content into the hygiene commit. macOS has no `timeout` binary; a watch is bounded by the Bash tool's timeout.
- 2026-09-03 (M51, corrected M52): the `test-coverage` job runs the suite under `covr` inside a 20-minute cap; serial it filled the cap, and with parallel files its step reads 9.9–12.0 min on identical code across attempts — so a CI-timing criterion reads the median of three attempts of one head, never a single run, and names its measured head by the net diff outside `cairn/`. The job never gates a merge (PROFILE test-doctrine): a red `test-coverage` beside green check legs is read from its log, and the merge proceeds on the check legs.
- 2026-09-03 (M55): `is.na()` on a factor answers `FALSE` for a value whose `NA` is a level (`addNA()`), though the value labels nothing; a check that asks whether a label is missing reads the column through `as.character()` first, and its fixtures plant the `addNA()` form beside the plain `NA`, since only the second was planted and the first passed review round 1.
- 2026-09-03 (M56): the `format-suggest` check goes red on any line air would reflow (over 80 characters included), and a fix pushed for it restarts the whole check matrix (the M50 line); run `air format --check` on the files a milestone touched before the review push, since the reviewdog thread names the line only after the run.
- 2026-09-03 (M57, trimmed 2026-09-05): under parallel test files a worker's teardown output reaches no log on either stream (measured, testthat 3.3.2), so a suite-level report printed at teardown is a serial-run report and `TESTTHAT_PARALLEL=FALSE` is how to read it.
- 2026-09-04 (M59): a mirai daemon has no UTF-8 console, so cli renders its `ℹ` bullet as `i` there while the host prints the glyph; a serial-versus-parallel identity test on note text (BC6) sees the two spellings differ on identical code, so it normalizes the glyph (or pins `cli.unicode` on both sides) before comparing.
- 2026-09-04 (M60): `withr::` in a test file is a `devtools::check()` WARNING, since withr is deliberately not a dependency (`helper-orchestration.R` says why); a temp tree in a test uses base `tempfile()` and registers `unlink()` in the calling `test_that()` block via `do.call(on.exit, ..., envir = parent.frame())`, which fires at the block's end.
- 2026-09-04 (M61): `nested_tune_bayes()` and `nested_tune_sim_anneal()` on a ranger workflow need a finalized `param_info` (`mtry` with unknowns fails every fold at inner tuning), and `min_n` bounded to the data too, since dials' default upper bound of 40 exceeds a 20-row inner analysis set and ranger warns on every fold with `rsq` `NaN`. Masking `lme4` also masks `BradleyTerry2` (it imports lme4), so one lme4-masked build exercises a notice's plural branch.
- 2026-09-05 (M63): a cli-built condition message printed in a knitted chunk carries its ANSI codes into the HTML; show it through `cli::ansi_strip()`. A `withCallingHandlers()` handler keeping the last warning prints the last one and errors on none; key it on the condition class.
