# M28: What we keep, what is only glue, and what belongs to rsample

**Status:** done (2026-08-30, PR #38 https://github.com/tidymodels/nestedtune/pull/38)

**Goal:** A concrete, cited list separating the code this package carries permanently from the glue that exists only because it sits outside `tune`, and from the pieces whose natural home is the resampling layer.

**Outcome:** Two documents, no package code changed. `cairn/references/code-inventory.md` sorts all 106 top-level definitions in `R/` — enumerated by one stated `grep`, merged against a separate name→bucket list by a script that refuses unequal name sets — into 32 `core`, 38 `furniture`, 16 `glue`, 12 `resampling-layer`, 8 `ambiguous`, each row carrying `file:line`, export status, line count and one bucket, plus the backtick-quoted `[.nested_results` as an addendum the pattern cannot match. Every `glue` entry cites tune at v2.1.0 (`4c74638`) and every `resampling-layer` entry cites rsample at v1.3.2 (`658545c`). Its load-bearing finding: the fact about being inside tune is the **absent stability promise, not absent visibility** — 13 of the cited tune symbols are exported but carry `#' @keywords internal` under four developer-facing topics (`empty_ellipses`, `internal-parallel`, `choose_metric`, `tune-internal-functions`). The page also states a re-runnable **upstream-counterpart sweep** (`grep -oE '^export\(([^)]+)\)' NAMESPACE` over both trees, 152 tune names and 62 rsample, read rather than name-matched against all 37 non-`core`/`furniture` entries). `benchmarks/upstream-asks.md` turns the 28 `glue` and `resampling-layer` entries into nine unposted asks — five to tune, four to rsample, one of them (T-A5) asking tune to change nothing — each entry under exactly one ask with a `Retires:` figure summed from the ledger.

**Decisions:** Milestone-local: buckets became five with `ambiguous` a bucket rather than an exemption; an exported-but-unpromised tune counterpart re-cites a `glue` entry rather than re-bucketing it wholesale, and moves the entry to `ambiguous` only where content tune's version does not cover remains; the re-export exclusion is a subtraction rule over the extraction output, never a name registry. Cross-cutting: none new — D-024 clause (2), D-025 and D-026 are cited, not amended.

**Review:** Four passes, single [O] diff-bug lens each (internal tier, markdown-only diff). Two amendment returns on AC6 (its "names the ask that would retire it" clause could not be met honestly while one entry had no ask) and two defect returns, both on AC2/AC6 and both on the same class — a claim about tune's export surface the instrument in hand did not reach: the first found nine cited symbols wrongly assumed unexported, the second a tenth (`new_bare_tibble`) never cited because nobody looked.
