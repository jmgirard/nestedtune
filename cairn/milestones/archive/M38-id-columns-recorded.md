# M38: A results object's own fold-label columns, recorded rather than guessed

**Status:** done (2026-08-31, PR #47 https://github.com/tidymodels/nestedtune/pull/47)

**Goal:** `nested_results` reads its own fold-label columns off a record the constructor wrote, so a column a caller adds is never mistaken for one the design named.

**Outcome:** `new_nested_results()` records `setdiff(names(resamples), c("splits", "inner_resamples"))` as the `id_columns` attribute. It joins `run_attributes()`, so `stamp_results()` and `copy_results_attributes()` carry it and `bare_results()` strips it. `id_columns()` now takes the object and returns that record; `record_columns()`, `has_results_columns()`, `fold_ids()`, `can_reconstruct_results()` and `template_record()` all read it, with `can_reconstruct_results()` and `vec_restore()` taking it from the *template* because dplyr hands the rule a bare frame for half the verbs. No name pattern survives. `can_reconstruct_results()` gained an `orderable()` guard so a label column `order()` cannot take — a list, or anything carrying a `dim` — returns `FALSE` instead of aborting from inside the rule. Three M36 defects close (`id2`/`id_extra` pasted into fold labels, an added `id2` unremovable, an added `id0` list column aborting with `unimplemented type 'list' in 'listgreater'`), plus the `orderVector1` abort. `NEWS.md` and the `@return` say what the code does; M36's narrowing sentence is gone.

**Decisions:** D-036 (the design's columns are recorded at construction and every reader takes the label set from that record; supersedes M36's milestone-local name-pattern decision and narrows D-031's invariant set). Milestone-local: the AC4 amendment at a mini gate, which anchored the criterion's method list to `NAMESPACE` plus a `reconstruct_results()` call and pinned each method's call shape.

**Review:** One round, three lenses. Two findings — an empty record answering with a malformed `collect_metrics()` table, and the constructor asserting nothing about a design with no label columns — were absorbed into the existing `check_nested()` candidate row. Six rejected with reasons. At hygiene, M36's lesson was trimmed to its uncovered remainder, the sweep now reddening on the mistake its prescription warned about.
