# M65: Three readers stack a per-fold list column with the fold labels beside it: `collect_notes()`, `collect_selections()` and `collect_inner_metrics()`

**Status:** done (2026-09-05, PR #75 https://github.com/tidymodels/nestedtune/pull/75)

**Goal:** Give `nested_results` three readers that stack a per-fold list column with the recorded fold labels beside it, so a user reads notes, selections and inner metrics across folds with one call instead of an apply loop that hardcodes `id`.

**Outcome:** `stack_fold_column()` in `R/nested-results.R` beside `fold_ids()` prepends the recorded label columns (`attr(x, "id_columns")`) to a per-fold list column and stacks with `vctrs::vec_rbind()`, refusing a stacked column named like a label column with class `nestedtune_collect_name_collision`. `R/nested-results-collect.R` holds `collect_notes.nested_results()` on tune's generic (re-exported in `R/reexports.R`, every fold, zero rows with the five columns on a clean run) and the package-owned generics `collect_selections()` and `collect_inner_metrics()`, whose defaults abort with `nestedtune_no_collect_method` and whose methods call `check_any_completed()` then `warn_partial_summary()` (class `nestedtune_partial_summary`) before stacking `.selected` or `.inner_metrics` over completed folds only, the column union with `NA` where a fold lacks one, `.config` kept. The internal per-run reader `collect_inner_metrics(tuned)` in `R/nested-tune-grid.R` became `inner_metrics_table()`. One help page (`man/collect_selections.Rd`) with executed examples, a `_pkgdown.yml` row under "Running the loop", a NEWS entry; `tests/testthat/test-collect-readers.R` (15 tests, a `stub_results()` builder for the union and repeated-design shapes) and three method-table entries in `test-nested-tune-bayes-oracles.R`.

**Decisions:** milestone-local, recorded at the plan gate: a method on tune's `collect_notes()` generic rather than an owned one; two owned generics with aborting defaults (the D-023, D-039 pattern; D-052); completed folds only with the partial warning, as `collect_metrics()` and `agreement()` read; `.config` kept in the stacked rows because it labels a row in that fold's own inner table; helpers over adding purrr to Suggests for the vignettes.
